# Curio — Revenue Model

## Three pricing tiers

### Free (Open Source Core)
```
curio watch ~/project
curio ask "question"
curio gaps
curio progress
```

- ✅ Local-first, runs on your machine
- ✅ Full learning loop
- ✅ Unlimited projects
- ✅ CLI + MCP server
- ❌ No cloud sync
- ❌ No team features
- ❌ No priority support

**Who:** Individual developers trying Curio
**Goal:** Adoption, community, GitHub stars

---

### Pro ($20/month)
```
curio watch ~/project --sync
curio team --add member@email.com
curio insights --weekly-report
```

- ✅ Everything in Free
- ✅ Cloud sync (knowledge graph backed up)
- ✅ Cross-device access
- ✅ Weekly learning reports (email digest)
- ✅ Priority support
- ❌ No team knowledge sharing

**Who:** Serious individual developers, freelancers
**Goal:** Revenue from power users

---

### Team ($50/user/month)
```
curio team --create "backend-team"
curio shared-knowledge --list
curio onboarding --new-developer "Sarah"
```

- ✅ Everything in Pro
- ✅ Shared team knowledge graph
- ✅ Onboarding mode (new devs learn faster)
- ✅ Admin dashboard
- ✅ SSO / SAML
- ✅ Audit logs for compliance
- ✅ Dedicated support

**Who:** Engineering teams, startups, enterprises
**Goal:** High-value recurring revenue

## What users pay for

Not the AI model — they bring their own API key for that.

They pay for:

1. **The learning loop** — gap detection, selective storage, forgetting, progress tracking. Nobody else does this.
2. **The knowledge graph** — curated, sourced, confidence-scored memory of their project. Not raw vector search.
3. **The audit trail** — every decision is explainable and reversible. Trust matters.
4. **Team knowledge sharing** — onboard new devs faster. institutional memory that doesn't leave when someone quits.
5. **The progress dashboard** — know what the team knows and doesn't know.

---

## Pricing psychology

- **Free tier** removes friction. Try it on any project, no credit card.
- **Pro at $20/mo** is below Copilot ($10) + ChatGPT Plus ($20). Justifiable for a dev tool.
- **Team at $50/user/mo** is below an engineer's hourly rate. If Curio saves 2 hours/month per dev, it pays for itself 10x.
- **Open source core** builds trust. Developers can inspect the code, verify privacy, contribute.

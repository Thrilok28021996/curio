# Curio — Launch Plan (Free Open Source)

## Strategy

```
Free forever → build community → prove value → add paid later
```

**Why free first:**
1. Gets maximum adoption with zero friction
2. Builds trust (developers love open source)
3. Validates the product with real users
4. Creates a community that contributes back
5. Proves demand before building paid features

**When to add paid:**
- After 1,000 GitHub stars
- After 500 active users
- After users ask for cloud sync / team features
- Not before — premature monetization kills open source projects

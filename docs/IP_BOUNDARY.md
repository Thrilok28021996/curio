# Curio — IP Boundary

## What Curio IS
- An independent product built by Thrilok as personal/side work.
- An autonomous learning agent that detects gaps, seeks knowledge, and improves over time.

## What Curio IS NOT
- It is not Broko.
- It is not a Broko feature.
- It is not built on Broko code, architecture, or infrastructure.
- It is not trained on Broko data, documents, or compliance corpus.
- It is not funded by or owned by Mantra Collab.
- It does not use Broko customers, contacts, or business relationships.

## Excluded assets (never use in Curio)
- Any Broko source code, scripts, config files, or architecture docs
- Any Broko compliance documents, markdown files, PDFs, or knowledge base content
- Any Broko Qdrant collections, embeddings, or vector stores
- Any Broko OneDrive/SharePoint files or paths
- Any Broko customer data, email threads, or internal communications
- Any Broko brand, domain, or marketing materials
- Any knowledge gained from working on Broko during employment hours

## What Curio MAY use
- Publicly available information (web, documentation, open-source repos)
- Independently created benchmark tasks and evaluation data
- Open-source libraries and frameworks
- Curio's own learned knowledge and memory

## Rule of thumb
If it came from Mantra Collab or was created during work on Broko, it cannot be used in Curio.
If it is publicly available or independently created by Thrilok, it can be used.

## For compliance
This IP boundary exists to protect both Thrilok and Mantra Collab.
It ensures Curio is provably independent and does not create any conflict of interest.
